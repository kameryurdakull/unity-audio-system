# Değişiklik günlüğü

## 1.0.0 — 2026-10-02

- Unity Package Manager için `com.kameryurdakull.audiosystem` paket düzeni hazırlandı.
- Tek SoundCatalog ve kalıcı sayısal ID’lerden projeye özel enum üretimi eklendi.
- 2D, sabit konumlu 3D ve Transform takipli 3D effect playback desteklendi.
- Sınırlı effect havuzu, priority/instance overflow, cooldown ve güvenli handle kontrolleri eklendi.
- İptal edilebilir, unscaled DOTween müzik fade/crossfade API’si eklendi.
- VContainer ve Event Bus entegrasyonu zorunlu bağımlılıklar olarak tanımlandı.
- Katalog inspector’ı, import/preview araçları ve setup penceresi eklendi.
- Generated çıktı klasörleri için Assets sınırı ve göreli örnek yolları desteklendi.
- Package Manager’dan import edilebilen bağımsız Playback Lab örneği hazırlandı.
- EditMode testleri ve Türkçe kurulum/kullanım rehberi eklendi.
